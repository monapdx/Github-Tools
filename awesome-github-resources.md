## README and Profile Builders

- [ReadmeForge](https://readmeforge.natrajx.in/) — Build SVG banners, badges, buttons, cards, and other components for a GitHub README.
- [GitHub Profile README Generator](https://rahuldkjain.github.io/gh-profile-readme-generator/) — Create a profile README from your information, skills, and social links.
- [GitHub Profile Summary Cards](https://github-profile-summary-cards.vercel.app/demo.html) — Generate customizable summary cards for a profile README.

## Badges, Icons, and Buttons

- [Shields.io](https://shields.io/) — Create static and dynamic badges for project metrics and custom labels.
- [For the Badge](https://forthebadge.com/) — Browse decorative badges or create custom SVG badges.
- [Simple Badges](https://badges.pages.dev/) — Find brand badges combining Simple Icons with Shields.io.
- [ReadmeCodeGen Badges Generator](https://www.readmecodegen.com/badges-generator) — Build badges through a visual interface.
- [badges.ws](https://badges.ws/) — Create configurable badges with colors, icons, and service integrations.
- [GitHub SVG Icons Generator](https://www.readmecodegen.com/icons/github-svg-icons-generator) — Choose technology icons for a README.
- [Dynamic Repository Badge Generator](https://dynamic-badges.ishanoshada.com/) — Browse repository-view badge and SVG banner styles. Some view-count examples contain placeholder domains; check generated URLs before use.
- [Made by Human](https://madebyhuman.iamjarl.com/) — Badges for labeling human-created work and creative involvement.
- [NodeICO](https://nodei.co/) — Display npm package information with customizable badges.
- [Skillful Import Button Generator](https://skillful.md/generator/) — Generate a README button that opens a repository import in Skillful.
- [Unofficial GitHub Buttons](https://ghbtns.com/) — Embed GitHub star, fork, follow, and sponsor buttons on websites.
- [CSS3 GitHub Buttons](https://necolas.github.io/css3-github-buttons/) — Style website links, buttons, and inputs as GitHub-style buttons.

## Repository Health and README Reviews

- [NxCode GitHub Repo Health Checker](https://www.nxcode.io/tools/github-repo-health-checker) — Inspect repository activity and receive a health score and recommendations.
- [README Score Checker](https://www.readmecodegen.com/readme-score-checker) — Evaluate a README and identify potential improvements.

## File Trees and Repository Diagrams

- [GitDiagram](https://gitdiagram.com/) — Turn a GitHub repository into an interactive diagram.
- [RepoTree](https://ascii-repotree.vercel.app/) — Generate ASCII directory trees from GitHub or GitLab repositories.
- [GitHub File Tree Visualizer](https://www.readmecodegen.com/file-tree/github-file-tree-visualizer) — View and copy a repository's folder structure.
- [GitHubTree](https://githubtree.mgks.dev/) — Explore repository trees, file sizes, and file breakdowns.
- [RepoAnalyzer](https://githubanalyze.vercel.app/) — Explore repository structure, copy file trees, and export analysis.

## Analytics, Activity, and Rankings

- [u8views](https://u8views.com/) — Track GitHub profile views with an embeddable badge and statistics.
- [GithubTracker](https://githubtracker.com/) — Track commits, issues, pull requests, contributors, and releases across repositories.
- [OSSInsight](https://ossinsight.io/) — Explore analytics for repositories, developers, and organizations. Its site currently notes that star-based rankings are paused because of incomplete event ingestion.
- [Gitstar Ranking](https://gitstar-ranking.com/) — Browse star-based rankings for users, organizations, and repositories.
- [GitRanks](https://gitranks.com/) — Explore GitHub developer, repository, organization, country, and language rankings.

## Browser Extensions

- [RepoKit](https://chromewebstore.google.com/detail/repokit-github-power-tool/kmembcacekbkoajacdcoakmlfaohanlj) — Add repository search, file sizes, ZIP downloads, and other browsing tools.
- [GitPing](https://chromewebstore.google.com/detail/gitping-github-notificati/eekhcmlieoegmlmfeidllpdklbkbfefj) — Receive notifications about issues, pull requests, and review requests.
- [GitHub Activity Tracker](https://chromewebstore.google.com/detail/github-activity-tracker/eedjcajcnflflfbbaijhhkenlkhigoak) — Monitor GitHub user activity, including repositories, issues, and pull requests.
- [Enhanced GitHub](https://chromewebstore.google.com/detail/enhanced-github/anlikcnbgdeidpacdbdljnabclhahhmd) — Display repository and file sizes, download individual files, and copy file contents.
- [Gitako](https://chromewebstore.google.com/detail/gitako-github-file-tree/giljefjcheohhamkjphiebfjnlphnokk) — Navigate repositories using a file-tree sidebar and search.
- [GitHub Recommender](https://chromewebstore.google.com/detail/github-recommender/hbiichfklkmlebacdfhkojcpmmakmamk) — Discover similar repositories based on repository descriptions.
- [Related Repos](https://chromewebstore.google.com/detail/related-repos/hjjchbgenhmnndipngamcilolaahgngc) — Find related repositories while browsing GitHub.
- [GIFs for GitHub](https://chromewebstore.google.com/detail/gifs-for-github/dkgjnpbipbdaoaadbdhpiokaemhlphep) — Add GIFs to GitHub conversations.

## First Contributions and Issue Discovery

- [First Contributions](https://firstcontributions.github.io/) — Follow a first-contribution tutorial and discover projects to contribute to.
- [For Good First Issue](https://forgoodfirstissue.github.com/) — Find contributions to digital public goods and projects with social impact.
- [GoodFirstIssue.org](https://www.goodfirstissue.org/) — Discover beginner-friendly open-source issues.
- [Good First Issue](https://goodfirstissue.dev/) — Browse approachable issues from popular open-source projects by language.
- [FirstIssues.dev](https://www.firstissues.dev/) — Find starter issues using language and repository-star filters.
- [First Timers Only](https://www.firsttimersonly.com/) — Learn how to make a first contribution and welcome new contributors.
- [CodeTriage](https://www.codetriage.com/) — Find open-source projects to help maintain and triage.
- [FindIssues](https://findissues.vercel.app/) — Find recent, unassigned GitHub issues by programming language.
- [Up For Grabs](https://up-for-grabs.net/#/) — Explore projects with tasks selected for new contributors.
- [GitHub Help Wanted](https://github-help-wanted.com/) — Browse GitHub contribution resources and help-wanted material.

## Contributor Recognition

- [All Contributors](https://allcontributors.org/en/) — Recognize code and non-code contributions with a specification and README automation.

## Publishing and Project Discovery

- [Branchpost](https://branchpost.dev/) — Generate blog drafts as GitHub pull requests for review and merging.
- [OpenHunts](https://openhunts.com/) — Discover and launch products on a community launch platform.

## Learning and Reference

- [Working with Non-Code Files](https://docs.github.com/en/repositories/working-with-files/using-files/working-with-non-code-files) — GitHub's documentation on viewing and working with non-code file formats.
- [GitHub Courses on Coursera](https://www.coursera.org/courses?query=github) — Browse courses about GitHub; enrollment terms and prices vary.
- [The Book of Secret Knowledge](https://github.com/trimstray/the-book-of-secret-knowledge) — Explore a large collection of technical references, tools, cheatsheets, and one-liners.
- [Awesome Interactive Fiction](https://tajmone.github.io/awesome-interactive-fiction/) — Explore interactive-fiction authoring tools, interpreters, learning material, and related resources.
